# Varsayılan rubrik

Resmi kural sayfasından ağırlık alınamayan yarışmalarda kullanılan tablo. Bir yarışma dosyası "varsayılan rubrik" diyorsa puanlar buradadır.

| Kriter | Ağırlık |
| --- | --- |
| Teknik | 25 |
| Yenilik | 20 |
| Etki | 20 |
| Demo | 20 |
| UX | 15 |

Toplam 100. Puan 0–10. Ağırlıklı skor = Σ(puan × ağırlık) / 100.
