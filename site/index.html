🛡️ Trust & Safety Architecture

  • Approval Gate: Sensitive actions (buy, post, export) require human sign-off via voice, Telegram, or Web UI.
  • BudgetLedger: Hard daily spending cap ($0.50) and per-run limits ($0.05). Refuses calls when exceeded.
  • Domain Allowlist: Strict CODE_ALLOWLIST blocks unauthorized or dangerous hosts.
  • Blast Radius: Every task outputs audited file count, domain list, and cost in blast_radius.json.
