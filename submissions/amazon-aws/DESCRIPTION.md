The strong tier can call Bedrock. Without keys the process logs a warning and stays on the mock model.

Set LLM_STRONG_PROVIDER=bedrock plus AWS_REGION, AWS_ACCESS_KEY_ID, AWS_SECRET_ACCESS_KEY, and BEDROCK_MODEL_ID.
